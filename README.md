# Tasca01-DVI · Gestió de lloguer de videojocs

És una aplicació de gestió per llogar videojocs on intervenen
usuaris, videojocs i lloguers. Les dades es guarden en memòria.

## Com executar-la

1. Obre el projecte amb NetBeans.
2. Fes Clean and Build.
3. Pitja RUN.
